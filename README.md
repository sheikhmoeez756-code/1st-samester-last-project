## ✨ Overview

BagBag is a fully responsive luxury bag store built with vanilla HTML, CSS, and JavaScript on top of Bootstrap 5. It pairs a dark, gold-accented aesthetic with a genuinely functional shopping experience — product browsing, filtering, a working cart, and account pages.

## 🚀 Features

- **Product catalogue** — men's & women's collections rendered from a JavaScript data model
- **Category filters** — filter each collection by type (backpacks, totes, handbags, sling bags)
- **Working cart drawer** — add items, adjust quantities, remove, live subtotal, and checkout
- **Product quick-view modal** — full details and add-to-cart from a popup
- **Login & Sign-up** — front-end demo auth with validation (accounts stored in `localStorage`)
- **Feedback form**, hero carousel, brand strip, gallery, and contact section
- **Custom logo & favicon** and a **fully responsive** layout with a mobile navbar

## 🛠️ Tech Stack

- **HTML5 / CSS3 / JavaScript (ES6+)**
- **Bootstrap 5** — layout, carousel, modal, offcanvas cart
- **Bootstrap Icons** & Google Fonts (Playfair Display + Poppins)
- **Deployment:** Vercel

## 📦 Getting Started

No build step — it's a static site. Just open it:

```bash
# clone, then open the folder
# option A: open index.html directly in a browser
# option B: serve it locally
npx serve .
```

## 📁 Project Structure

```
index.html      # Markup for all sections
style.css       # Dark-luxury theme & responsive rules
script.js       # Products, cart, filters, modal, cart drawer
auth.js         # Demo login/sign-up logic (localStorage)
login.html      # Sign-in page
signup.html     # Create-account page
auth.css        # Auth page styling
logo.svg        # Brand logo
img/            # Product, brand, and gallery images
```

## 📝 Notes

This is a **front-end demonstration**: the cart and accounts persist in the browser via `localStorage`, and there is no payment backend. Auth is for demo purposes only (passwords are not encrypted).
